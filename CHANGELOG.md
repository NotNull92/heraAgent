# Changelog

## 0.1.0-alpha.1

Initial local Codex client, strict settings, isolated official authentication,
native thread references, Korean-aware TUI, conservative safety gates and package
checks. Official Windows sandbox setup, observed native worker lifecycle probes, and
change review/apply/test flow are implemented. Native GPT worker trees, task/result
validation, recursive cancellation and main-only apply transitions have Windows live
evidence and require matching local verification. Persistent OS provider credentials
and interactive model/effort/worker/provider menus are available. Go direct/native
tool access has Windows evidence; cross-provider collaboration remains gated.
This is a development prerelease, not a fully accepted M0-M7 release.
