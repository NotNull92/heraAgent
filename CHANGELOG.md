# Changelog

## 0.1.0-alpha.1

Local Codex client with strict settings, isolated official authentication, native
history/resume, Windows sandbox setup and Korean-aware TUI. Ordinary tasks edit and
test immediately with native on-request approvals; `/plan` remains read-only.
GPT-only, GPT-root/Go-worker and adaptive Go-root/Astra modes require matching local
native-workflow verification. Design/research requests automatically assign 3-5
DRD questions through native collaboration and public Playwright evidence gathering.
Credentials persist in OS stores. The TUI has terminal scrollback, a live footer,
themed menus and a resize redraw fix; the obsolete phase track is removed.
It honors NO_COLOR, ui.color and ui.reducedMotion. macOS manual/live is not certified.
This is a development prerelease, not a fully accepted M0-M7 release.
