# Hera artwork

The README hero is an original adult female character created for Hera on
2026-10-08 with the built-in image generation tool. The requested direction was
2D Japanese anime with an office outfit and a voluptuous adult silhouette.
The final design uses ink-black/teal hair, amber eyes, an ivory blouse, a dark
suit and a gold four-point star, echoing the terminal's gold accents.

Asset: [hera-hero.png](../assets/branding/hera-hero.png), 1536 × 1024 PNG.
The same image is used across the English, Korean and Japanese READMEs.
No reference artwork was copied into the shipped asset.
